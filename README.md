# nanum_cookierun
The simple cookie run game using Pictoblox. It's kind a educational game for students with intellectual disabilities
- Final code in main branch.
- Weekly educational materials and step-by-step code are located in week-n branch.

## Pictoblox로 게임 만들기
주차 별 Branch를 통해 단계 별로 나만의 쿠키런 게임을 구현해보자!

### 게임 소개
> 나만의 간단한 쿠키런 게임
- 장애물을 피해 달리고 점프해 마녀의 오븐을 탈출하자.
- 만세 (= 점프), 차렷 (= 달리기) 모션을 통해 조작.
- 장애물 충돌 시 HP 감소. 총 5번 충돌 시 게임 종료.
- 누가누가 오래 버틸까. 1초=1점.
